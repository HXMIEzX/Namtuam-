# เฝ้าระวังน้ำไทย

เว็บแผนที่แสดงข้อมูลสถานีตรวจวัดระดับน้ำทั่วประเทศไทยจาก API สาธารณะของคลังข้อมูลน้ำแห่งชาติ (ThaiWater) พร้อมเครื่องมือค้นหาเส้นทางขับรถระหว่างสถานที่

หน้าแรกเป็นภาพรวม จากนั้นเลื่อนลงเพื่อดูแผนที่ขนาดใหญ่ โดยมีแถบการแจ้งเตือนสถานีล้นตลิ่งและปุ่มโทรสายด่วนอยู่ด้านซ้ายบนจอคอมพิวเตอร์

## เข้าสู่ระบบด้วย Google

เว็บใช้ Firebase Authentication กับ Google provider และเก็บสถานะการเข้าสู่ระบบไว้ในเบราว์เซอร์ของผู้ใช้ ยังไม่มีการเก็บข้อมูลผู้ใช้ลงฐานข้อมูล

1. ใน Firebase Console เลือกโปรเจกต์ `namtuam-d7be6` แล้วเปิด **Authentication**; หากยังไม่เคยตั้งค่า ให้กด **Get started**
2. ใน **Authentication → Sign-in method** เปิดผู้ให้บริการ **Google** แล้วกด Save
3. ไปที่ **Authentication → Settings → Authorized domains** แล้วเพิ่มโดเมนที่ใช้จริง เช่น `localhost` สำหรับทดสอบ และโดเมนเว็บไซต์ที่ deploy
4. เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ เช่น Live Server หรือ `python -m http.server` ไม่ควรเปิดไฟล์ด้วย `file://` เพราะ Google sign-in ต้องใช้ authorized web domain
5. บนคอมพิวเตอร์ใช้หน้าต่าง popup; บนมือถือใช้ redirect เพื่อให้เข้ากับเบราว์เซอร์มือถือ

หากพบ `auth/configuration-not-found` ให้ตรวจว่ามีการกด **Get started** เพื่อเปิดใช้ Firebase Authentication แล้ว, เปิด Google provider และเลือกโปรเจกต์ `namtuam-d7be6` ให้ตรงกับ `projectId` ใน `firebase-auth.js` หากตั้งค่าครบแล้วแต่ยังพบปัญหา ให้ตรวจว่า Web App config ในไฟล์มาจากโปรเจกต์เดียวกัน

Firebase Web config ที่อยู่ใน `firebase-auth.js` เป็น client config สำหรับเว็บ ไม่ใช่ service-account/private key ห้ามนำ private key มาใส่ใน frontend

## ที่พักพิงและสถานพยาบาลใกล้ตำแหน่งปัจจุบัน

กดค้นหาสถานที่และอนุญาต Location เพื่อค้นหาที่พักพิง โรงพยาบาล คลินิก และสถานีอนามัยในรัศมี 20 กม. จาก OpenStreetMap; ตำแหน่งจะถูกใช้เฉพาะเมื่อผู้ใช้กดค้นหาหรือนำทาง และไม่ถูกส่งไปเก็บในระบบของเว็บไซต์ ระบบแสดงเบอร์โทรเมื่อมีระบุไว้ในข้อมูลแผนที่เท่านั้น ข้อมูลอาจไม่ครบหรือไม่เป็นปัจจุบัน จึงควรโทรยืนยันกับสถานที่ก่อนเดินทาง

เลือกนำทางเพื่อคำนวณเส้นทางขับรถจากตำแหน่งที่ตรวจพบในขณะนั้นด้วย OSRM โดยต้องเปิดเว็บผ่าน HTTPS (localhost รองรับการทดสอบตำแหน่ง) เส้นทางคำนวณจากข้อมูล OpenStreetMap และไม่ยืนยันการเปิดถนนหรือความปลอดภัยหน้างาน

จากผลค้นหาแต่ละแห่งสามารถเปิด Google Maps พร้อมต้นทางเป็นตำแหน่งปัจจุบันและปลายทางเป็นสถานที่นั้นได้ ส่วนการเปิด Google Maps จาก route planner จะส่งชื่อจุดต้นทาง/ปลายทางไปให้ Google Maps คำนวณเส้นทางของ Google เอง เว็บไซต์นี้ไม่ได้ใช้ Google Maps Platform API หรือแสดง traffic/closure layer จาก Google; การใช้ Google Maps ในแอปพลิเคชันและการฝังแผนที่มีข้อกำหนด API key/การเรียกเก็บเงินแยกต่างหาก

## ข่าวและการแจ้งเตือนเหตุการณ์

ส่วนข่าวอ่านฟีด RSS ล่าสุดของข่าวสดผ่าน RSS2JSON แล้วกรองหัวข้อที่เกี่ยวกับน้ำท่วม/ภัยน้ำและอัปเดตทุก 15 นาทีขณะเปิดหน้าเว็บ มีลิงก์ Google News สำรองสำหรับค้นข่าวจากสำนักข่าวหลายแห่ง การแจ้งเตือนบนหน้าจอเป็นตัวเลือกที่ผู้ใช้ต้องกดอนุญาต และจะแจ้งเฉพาะบทความใหม่ในระหว่างที่หน้าเว็บยังเปิดอยู่ ไม่ใช่ push notification เมื่อปิดเว็บไซต์ ข่าวเป็นรายงานจากสื่อ ไม่ใช่ประกาศภัย/ปิดถนนทางการ

## ภาษาและยอดเข้าชม

ปุ่ม EN/TH เปลี่ยนภาษาหน้าเว็บและบันทึกค่าที่เลือกไว้ในเบราว์เซอร์

ปุ่มธีมมืด/สว่างที่แถบด้านบนเปลี่ยนสีหน้าเว็บและบันทึกค่าที่เลือกไว้ในเบราว์เซอร์; ค่าเริ่มต้นคือธีมสว่าง

ยอดเข้าชมใช้ GoatCounter นับ pageview จริง โดยสคริปต์ไม่นับ `localhost` และ IP loopback เพื่อไม่รวมการทดสอบในเครื่อง ก่อนนับผู้เข้าชมจริง:

1. สร้างไซต์ฟรีที่ [GoatCounter](https://www.goatcounter.com/) และตั้ง site code เป็น `namtuam` (หรือแก้ค่า `goatcounter-code` ใน meta tag ของ `index.html` ให้ตรงกับ code ที่สมัครไว้)
2. ตั้งค่าโดเมน production ใน GoatCounter และเผยแพร่เว็บผ่าน HTTPS; บัญชีที่สร้าง site code ต้องจอง `namtuam` ได้ หรือแก้ meta tag ให้เป็น code ที่สร้างจริง
3. ยอดรวมอ่านจาก public counter API ของ GoatCounter; หาก site code ยังไม่ถูกสร้าง/ตั้งค่าหรือบริการยังเข้าถึงไม่ได้ หน้าเว็บจะแสดงว่าเชื่อมต่อไม่ได้ ไม่แสดงเลขสมมติ ขณะเปิด `localhost` จะแสดงข้อความว่ายอดจริงจะแสดงเมื่อเผยแพร่เว็บ และจะไม่ส่งคำขอไปยังตัวนับ

ตัวเลขนี้หมายถึงจำนวนการเปิดหน้า (pageviews) ที่ GoatCounter รับรู้ ไม่ใช่จำนวนผู้ใช้ที่ไม่ซ้ำกัน

## เริ่มใช้งาน

เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static เช่น Live Server หรือ `python -m http.server` แล้วเปิดหน้าเว็บในเบราว์เซอร์ ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Leaflet, แผนที่ OpenStreetMap และข้อมูลสถานีจาก ThaiWater

หน้าเว็บปรับการจัดวางอัตโนมัติตามขนาดหน้าจอ รองรับคอมพิวเตอร์ แท็บเล็ต/iPad และโทรศัพท์/iPhone รวมถึงการแตะและหมุนจอ โดยต้องใช้เบราว์เซอร์รุ่นปัจจุบันและอินเทอร์เน็ต

## ค้นหาเส้นทาง

กรอกต้นทางและปลายทางเป็นชื่อสถานที่ในประเทศไทย ระบบค้นหาพิกัดด้วย Photon และคำนวณเส้นทางขับรถด้วย OSRM จากข้อมูล OpenStreetMap แล้วแสดงถนน/ช่วงถนนตามโครงข่ายแผนที่ ระยะทาง เวลาโดยประมาณ และสถานีที่รายงานระดับน้ำเสี่ยงใกล้แนวถนน

ผล “มีเส้นทางในแผนที่” หมายถึงระบบเส้นทางคำนวณการเชื่อมต่อถนนได้เท่านั้น ขณะนี้เว็บไม่มี live feed ที่เชื่อถือได้สำหรับยืนยันถนนปิดหรือน้ำท่วมบนถนน จึงไม่สามารถรับรองว่าส่วนใด “ไปได้” หรือ “ไปไม่ได้” ในสถานการณ์จริง และการไม่พบสถานีระดับน้ำเสี่ยงใกล้ถนนไม่ใช่หลักฐานว่าถนนปลอดภัย ตรวจสอบข้อมูลจราจรจาก [กรมทางหลวง](https://highwaytraffic.go.th/DOHWeb/Home.aspx) หรือโทร 1586 ก่อนเดินทาง

## สายด่วน

- 1784 แจ้งเหตุสาธารณภัย — [กรมป้องกันและบรรเทาสาธารณภัย](https://www.disaster.go.th/)
- 1669 การแพทย์ฉุกเฉิน — [สถาบันการแพทย์ฉุกเฉินแห่งชาติ](https://www.niems.go.th/)
- 191 เหตุด่วนเหตุร้าย — [สำนักงานตำรวจแห่งชาติ](https://www.royalthaipolice.go.th/)
- 1586 สอบถามเส้นทางทางหลวง — [กรมทางหลวง](https://www.doh.go.th/)

หมายเลขโทรศัพท์ใช้ลิงก์ `tel:` เพื่อโทรจากอุปกรณ์ที่รองรับ โปรดตรวจสอบกับหน่วยงานเจ้าของสายด่วนหากมีการเปลี่ยนแปลง

## แหล่งข้อมูลและการอ่านสถานะ

- ข้อมูลระดับน้ำและพิกัดสถานี: [ThaiWater public API](https://api-v3.thaiwater.net/api/v1/thaiwater30/public/waterlevel_load)
- หน่วยงานเจ้าของข้อมูล: [คลังข้อมูลน้ำแห่งชาติ — ThaiWater](https://www.thaiwater.net/)
- แผนที่ฐาน: [OpenStreetMap](https://www.openstreetmap.org/copyright)
- ค้นหาสถานที่: [Photon](https://photon.komoot.io/)
- คำนวณเส้นทาง: [OSRM demo server](https://router.project-osrm.org/)
- ค้นหาที่พักพิง/สถานพยาบาลใกล้ตำแหน่ง: [OpenStreetMap Overpass API](https://overpass-api.de/)
- ฟีดข่าว: [ข่าวสด RSS](https://www.khaosod.co.th/feed) ผ่าน [RSS2JSON](https://rss2json.com/)
- นับ pageview: [GoatCounter](https://www.goatcounter.com/)
- สถานะน้ำล้นตลิ่งอ้างอิงระดับสถานการณ์จากข้อมูล ThaiWater (ระดับ 5) หรือข้อความรายงาน “ล้นตลิ่ง” จากสถานี
- ระดับ 4 แสดงเป็น “น้ำมาก”; ระดับ 1–3 แสดงเป็น “ไม่พบรายงานล้นตลิ่ง”
- ข้อมูลที่เก่ากว่า 24 ชั่วโมงหรือไม่มีระดับสถานการณ์จะแสดงแยกเป็นข้อมูลเก่า/ไม่ระบุ และไม่นับในสรุปสถานีล่าสุด

สถานะในแผนที่เป็นสถานะ ณ จุดตรวจวัด ไม่ได้ยืนยันขอบเขตน้ำท่วมของทั้งจังหวัดหรือพื้นที่ระหว่างสถานี การไม่มีรายงานจากสถานีไม่ใช่หลักฐานยืนยันว่าไม่มีน้ำท่วม ควรตรวจสอบประกาศของหน่วยงานในพื้นที่ประกอบเสมอ
